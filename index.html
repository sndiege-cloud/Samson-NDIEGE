📖 Lesson 1: What is Programming?

Programming is the process of writing instructions that a computer can follow. These instructions are called code, and they are written in a programming language like JavaScript, Python, or Java.

Key Concepts

Variable

A named container that stores a value. Example: let score = 10;

Function

A reusable block of code that performs a task. Example: function greet() { }

Loop

Repeats code multiple times. Example: for (let i = 0; i < 5; i++) { }

Condition

Runs code only if something is true. Example: if (score > 50) { }
